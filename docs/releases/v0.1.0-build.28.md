## 本次改动

- **多订阅组合**：在“订阅 → 组合订阅”勾选 2–16 个来源，选择基础配置与兜底出口；保留单订阅模式。节点与策略组按来源隔离，并保留成员显式节点 DNS，修复聚合后部分节点无法测速的问题。
- **统一分流编辑器**：支持完整域名、域名后缀、关键词、IPv4 / IPv6 网段、进程名称和路径；出口可选成员订阅、策略组、直连或拒绝。支持批量添加、排序、启停和当前草稿的本地匹配预览。预览不解析 DNS、不模拟远程规则集，实际出口以新连接为准。
- **快捷分流与诊断**：从连接右键创建域名或应用规则；连接详情显示规则、来源与代理链；增加网络诊断和订阅更新变化。应用匹配依赖流量进入 LumaRoute 及已授权后台服务的进程识别能力。
- **规则保存提速**：纯规则变更采用专用后台更新路径，减少重复生成与校验，保留内核进程、已有连接、测速和观察任务。节点、DNS、端口或其他拓扑变更继续走完整配置应用。
- **界面响应**：后台状态同值不重复通知；菜单结构未变时复用项目；切页按缓存时效刷新；已访问页面保留搜索、展开与草稿。组合出口候选在后台生成并缓存，加载完成后才判断出口是否失效。
- **运行与存储**：未变化的订阅内容不重载配置；自动下载独立排队，流量及日志异常后重连；SQLite 写入移至串行存储队列并采用增量事务；按引用保护运行缓存和备份。

## 性能与验证

Build 28 与 Build 27 使用同一份私有测试数据、依次运行原生宿主。重复菜单准备中位数 **57.16 → 0.53 ms**，重复编辑器候选查询 **27.78 → 0.26 ms**。可见窗口实际点击对照中，代理页切换 **157.7 → 71.9 ms**，设置页 **90.4 → 46.1 ms**；计时从页面状态变化至布局 / display 提交，不等同于物理输入到出帧，样本不足以承诺所有机器上的 P95。首次候选生成未宣称提速。

Build 27 已完成真实后台服务规则保存验收：新增和删除规则分别约 **324 / 302 ms**，包含 AppStore、XPC、内核应用与 SQLite 提交，不包含按钮输入和窗口关闭渲染；保存期间原有流式连接保持。此结果随 Build 28 一并交付。

- Build 28：218 项 CLI 核心断言、41 项 UI / 刷新 / 缓存检查通过；设置刷新、运行恢复及 9 项实际 AppStore / SQLite 组合检查通过。
- 既有多订阅、七种分流匹配、节点 DNS 与规则保存使用隔离的真实 Mihomo 请求验收，记录见下方链接；本次打包不重启用户应用或在线内核。
- DMG、ZIP 解包后核对 Build 28、arm64 架构、文件清单与 SHA-256、权限及嵌套签名；发布提供校验文件。不包含用户数据库、订阅链接、凭据或私有测试快照。
- 当前 CLT 环境未执行 XCTest，也未新增完整的 TUN 接管、首次授权、登录自启和物理断网验收。

## 安装与更新

1. 关闭系统代理和 TUN，退出 LumaRoute，在原安装位置替换 `LumaRoute.app`。
2. 打开应用；若显示“完成更新”，点击并在 macOS 管理员授权窗口确认，完成后自动连接服务。
3. 从 **Build 21 及以后版本更新保留 SQLite 业务数据**，无需重建订阅或组合。首次使用时先添加订阅，再按需启用系统代理或 TUN。
4. 从 **Build 20 或更早版本更新**不自动迁移旧 JSON、订阅文件或钥匙串数据，需重新添加订阅；旧文件原样保留。普通备份不包含完整订阅链接与控制密钥。

本包包含 Mihomo、GEO 数据、图标、许可及后台服务。已采用 `/Applications/LumaRoute/LumaRoute.app` 路径的用户继续在该位置更新，应用名称保持 LumaRoute。后台服务绑定具体构建，新版可能需要一次授权同步；同一已授权构建正常重开无需重复安装。

本包采用 **ad-hoc 本地签名，未使用 Developer ID，也未经过 Apple 公证**。签名完整性通过不代表 Gatekeeper 分发信任通过。下载后若被阻止，确认来源后按“系统设置 → 隐私与安全性”提示手动允许，或按 README 在本机自行构建；无需关闭 Gatekeeper 或系统完整性保护。
