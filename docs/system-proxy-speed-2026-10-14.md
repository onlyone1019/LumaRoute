# 系统代理独立开关与速度验收

2026-10-14，Build 18 已安装到 `/Applications/LumaRoute.app`，本机后台服务同步完成，主程序和 helper 的哈希与服务快照一致，深度严格签名校验通过。

## 改动

- 概览、菜单栏和连接入口仅切换系统代理时，发送独立 `system-proxy` 请求；设置页只改系统代理并应用时也使用此路径。重复设置直接返回。
- 请求只携带开关值，后台从已成功运行的配置取得端口、绕过列表和 TUN 状态，保留用户归属、网络占用、待恢复状态及内核运行检查。
- 修改系统代理时不生成或校验 YAML、不重载内核、不恢复节点选择、不重启流量/日志流，也不修改 DNS。后台保留原设置 journal 与冲突检查；失败尝试恢复上次代理状态，恢复失败沿用停止接管流程。
- 同时修改 TUN、端口、DNS 等设置仍使用完整配置流程；内核尚未进入服务运行状态时也保留原启动路径。

## 速度

同一台 Mac、相同真实订阅配置，每个版本在概览页开启和关闭各三次。从 CUA 发出点击前计时，到界面显示目标状态且开关解除禁用为止；此口径包含自动化输入和界面观察开销。

| 操作 | Build 17 平均 | Build 18 平均 | 耗时减少 |
| --- | ---: | ---: | ---: |
| 开启 | 5.329 秒 | 0.823 秒 | 84.6% |
| 关闭 | 4.908 秒 | 0.875 秒 | 82.2% |

旧版开启样本：4585 / 6053 / 5350 ms；关闭：4321 / 5184 / 5218 ms。

新版开启样本：870 / 836 / 763 ms；关闭：855 / 934 / 835 ms。

新版应用内计时从发送后台请求前，到成功保存本地设置后：开启 10 / 8 / 9 ms，关闭 9 / 10 / 9 ms。它与上表的界面观察口径不同，不能拿来直接计算旧版到新版的倍数。另在设置页开启、关闭各一次，分别为 7 / 7 ms。应用内计时也不包含 macOS 后续传播有效代理状态的时间。
