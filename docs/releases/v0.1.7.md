# LumaRoute 0.1.7 · Build 37

修复连接页持续刷新时的自动行高重入风险，绕开原崩溃报告中的 AppKit 自动测高路径。保留现有原生扁平界面、表格列、排序、筛选、选择与分流入口。

## 本次更新

- 连接表格通过窄范围的 AppKit 桥接自行创建，始终使用固定的 24 点单行行高，避免实时行变化时进入 AppKit 的自动行高缓存递归。
- 排序、选择与分流状态仍由原页面管理；页面回收重建后也保持固定行高，其他页面的行高行为保持不变。窄窗口可横向滚动查看各列。
- 新增真实连接页 GUI 回归，覆盖连接骤增、整批替换、清空、排序、筛选、原生行选择、滚动、窗口尺寸变化、主题切换和页面重建。崩溃、超时、重入警告或自动测高重新开启都会导致检查失败。
- 增加持续刷新模式，覆盖真实 60 秒空闲页面回收；CI 在 Apple Silicon 构建后运行快速 GUI 回归。

发布前分别验证 Apple Silicon 和 Intel 产物，结合调试器调用统计与 GUI 持续刷新验证，检查原报告中的自动测高路径已经停用。原报告的 SIGSEGV 未能稳定复现，因此测试同时检查实际自动测高调用和行高模式，避免仅凭短时间未崩溃判断修复成功。Swift 6、macOS 27.0 SDK 和 macOS 14 最低支持版本保持不变；详细测试结果随 `source-manifest.json` 提供。

## 安装与更新

需要 macOS 14 或更新版本。M 系列 Mac 选择 `arm64`，Intel Mac 选择 `x86_64`；均提供 DMG 和 ZIP。

更新前关闭 LumaRoute 的系统代理和 TUN，再退出应用，将新包替换到 `/Applications/LumaRoute.app`。重新打开后如出现“完成更新”，点击并在 macOS 管理员授权窗口确认。从 Build 21 及以后版本更新会保留现有 SQLite 数据。从 Build 20 或更早版本更新需重新添加订阅，旧文件保留。

安装包使用本地 ad-hoc 签名，未经过 Apple 公证。下载后如被系统阻止，请在“系统设置 → 隐私与安全性”按提示允许打开。Intel 产物通过 Apple Silicon 上的 Rosetta 验证，尚未完成 Intel 真机验收。本次发布验证不替换本机已安装应用或后台服务，也不执行真实系统代理、DNS 或 TUN 接管。
