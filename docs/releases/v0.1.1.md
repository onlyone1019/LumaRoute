# LumaRoute 0.1.1 · Build 31

新增应用自身的检查更新功能，沿用现有原生界面样式。

## 本次更新

- 在“设置 → 更新与备份”、LumaRoute 应用菜单和菜单栏菜单中增加“检查更新”。
- 查询 GitHub 正式 Release，比较版本号与 Build 号，显示是否有新版。
- 发现新版后，可查看更新说明并下载适合本机架构的 DMG 安装包。
- 检查失败时显示原因；检查过程不修改当前订阅、系统代理或 TUN 设置。

本版提供手动检查和下载入口，下载后仍需手动替换应用。

## 安装与更新

需要 macOS 14 或更新版本。M 系列 Mac 选择 `arm64`，Intel Mac 选择 `x86_64`；均提供 DMG 和 ZIP。

更新前关闭系统代理和 TUN，退出应用，在原安装位置替换后重新打开。若出现“完成更新”，点击并在 macOS 管理员授权窗口确认即可。从 Build 21 及以后版本更新会保留现有配置。

安装包使用本地 ad-hoc 签名，未经过 Apple 公证。下载后如被系统阻止，请在“系统设置 → 隐私与安全性”按提示允许打开。

Intel 包在 Apple Silicon 上通过 Rosetta 验证，尚未完成 Intel 真机验收。
