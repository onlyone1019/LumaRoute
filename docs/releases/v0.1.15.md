# LumaRoute 0.1.15 · Build 45

修复应用更新后“网络服务同步失败：请先在应用中关闭接管并恢复网络，再维护服务”的问题。

- 自动清理已删除网络服务或协议的失效恢复记录。
- 同步服务时先停止旧服务，由已校验的新后台组件完成必要的网络恢复，确认恢复记录清空后再替换安装。
- 恢复失败时保留记录和旧安装并恢复旧服务；已被其他代理软件修改的设置按原有归属检查保留。

升级后如显示“完成更新”，点击并在 macOS 授权窗口中确认即可，无需手工删除系统文件。保留 0.1.14 的文本选中与单击编辑修复。

需要 macOS 14 或更新版本。内置 Mihomo 继续使用 v1.19.33。提供 Apple Silicon / Intel 双架构 DMG、ZIP、签名更新源、源码及 SHA-256 校验文件。安装包为本地 ad-hoc 签名，未经过 Apple 公证；Intel 为交叉构建，未做 Intel 真机验收。

## 验证

104 项 Swift 单元测试、47 项脚本测试通过。新增恢复验收覆盖已删除服务/协议、仍归属 LumaRoute 的配置恢复、其他软件的代理设置保留、提交失败时保留恢复记录，以及服务升级失败时保留并重启旧服务。新的维护入口只接受管理员进程，不增加 XPC 操作。
