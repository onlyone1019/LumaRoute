# LumaRoute 0.1.21 · Build 51

在「订阅 → … → 订阅设置」中粘贴新链接并保存，即可更换现有远程订阅的地址。留空可单独修改下载方式或 User-Agent。订阅列表只显示脱敏后的地址，完整链接保存在本机。

点击「更新」可立即拉取新配置，后续自动更新也会使用新链接。换地址会保留该订阅的配置和组合订阅引用。新链接刷新失败时，仍可使用上次下载成功的节点。

需要 macOS 14 或更新版本，内置 Mihomo v1.19.34。可从应用内「检查更新」下载并安装。如出现「完成更新」，按 macOS 提示授权同步后台服务。

提供 Apple Silicon 和 Intel 的 DMG、ZIP、签名更新源、源码及 SHA-256 校验文件。安装包使用 ad-hoc 签名，未经过 Apple 公证。
