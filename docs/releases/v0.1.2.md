# LumaRoute 0.1.2 · Build 32

降低日志与页面缓存的内存开销，保留现有原生界面和快速切页体验。

## 本次更新

- 日志导出仅在点击“导出诊断”时生成文件内容，完成、失败或取消后释放导出文本；继续保留凭据脱敏。
- 恢复实时日志时释放旧的暂停快照。
- 停止切页 60 秒后，回收非当前的日志、连接页面；再次打开时保留搜索、筛选、选择、排序、滚动位置和连接表格列宽。
- 普通切页继续复用缓存，设置、规则等编辑页面继续保留草稿；正在导出或编辑连接规则的页面不回收。

在相同 2000 条日志、300 个连接的隔离 Release 测试中，空闲后物理内存由 174.5 MiB 降至 93.0 MiB；普通切页布局耗时中位数由 316 ms 降至 125 ms。回收后首次返回日志页由 342 ms 降至 266 ms。它们是固定场景的本机结果，切页计时包含主队列回合与布局，不代表所有配置的内存降幅或端到端呈现延迟。

23 项界面与生命周期检查通过，日志、连接、设置页的前后截图完全一致；实际系统保存对话框的取消、再次导出与完整文件写出均已验证。完整方法见[内存优化测试记录](../memory-optimization-2026-10-16.md)。

## 安装与更新

需要 macOS 14 或更新版本。M 系列 Mac 选择 `arm64`，Intel Mac 选择 `x86_64`；均提供 DMG 和 ZIP。

更新前关闭系统代理和 TUN，退出应用，在原安装位置替换后重新打开。若出现“完成更新”，点击并在 macOS 管理员授权窗口确认即可。从 Build 21 及以后版本更新会保留现有配置。

安装包使用本地 ad-hoc 签名，未经过 Apple 公证。下载后如被系统阻止，请在“系统设置 → 隐私与安全性”按提示允许打开。

Intel 包在 Apple Silicon 上通过 Rosetta 验证，尚未完成 Intel 真机验收。
