# LumaRoute 0.1.8 · Build 38

接入 Sparkle 应用内更新，在原有“检查更新”入口下载新版，确认后自动安装并重新启动。保留现有原生扁平界面、订阅配置和节点选择。

## 本次更新

- 支持检查更新、下载进度、取消下载、安装及自动重新启动；第一版仅手动检查，不启用后台检查、自动下载或静默安装。
- 更新源与 ZIP 使用 EdDSA 签名校验，并检查来源、处理器架构和递增 Build。Apple Silicon 和 Intel 分别提供签名更新源。
- 安装前保存一次性的网络恢复状态，等待系统代理和 TUN 恢复后退出；恢复失败时阻止安装退出。新版启动后按原状态继续连接，需要同步后台服务时使用现有管理员授权流程。
- 保留应用包外的 SQLite 数据、订阅、规则、节点选择和外观设置，修复服务重建时已保存节点选择未实际应用的问题。
- 更新弹窗、按钮及设置页提示使用中文，区分取消、网络超时、更新源不可用、下载失败和校验失败；修复取消检查后仍显示“正在检查更新…”的问题。

## 安装与更新

需要 macOS 14 或更新版本。M 系列 Mac 选择 `arm64`，Intel Mac 选择 `x86_64`；均提供 DMG 和 ZIP。

0.1.7 及更早版本首次迁移需要手动安装一次：先关闭系统代理和 TUN，退出应用，把新版替换到 `/Applications/LumaRoute.app`。已安装带 Sparkle 构建的用户可以直接检查更新并选择“安装并重新启动”。更新后若出现“完成更新”，请在本机 macOS 管理员授权窗口确认；取消后可以稍后重试。

从 Build 21 及以后版本更新保留现有 SQLite 数据。从 Build 20 或更早版本更新需重新添加订阅，旧文件保留。更新和管理员授权不会要求向聊天或仓库发送密码。

安装包仍使用本地 ad-hoc 签名，未使用 Developer ID，也未经过 Apple 公证。下载后如被系统阻止，请在“系统设置 → 隐私与安全性”按系统提示允许打开，或按 README 从源码构建。Intel 产物为交叉构建，尚未完成 Intel 真机的系统代理和 TUN 验收。

## 验证与已知限制

已通过真实 Sparkle 的下载、替换与重启、取消检查/下载、签名/来源/架构拒绝、更新源 404、下载失败和网络恢复失败时阻止退出等 12 组隔离更新流程，以及 8 组中文错误提示检查。Apple Silicon 实机已完成备份、管理员服务同步、系统代理/TUN 恢复和配置保留验收；9 张配置表一致，3/3 已保存节点选择在内核中保持生效。详见 [应用内更新说明](https://github.com/onlyone1019/LumaRoute/blob/v0.1.8/docs/app-updates.md)。

更新源托管在 GitHub。当前网络直连 GitHub 不稳定时，检查更新可能等待较长时间；本版仍使用默认请求超时，尚未加入更短的总超时或独立更新镜像。可以取消后稍后重试。
