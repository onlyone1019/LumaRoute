# LumaRoute 0.1.0 · Build 30

首个正式发布版本，适用于 macOS 14 及更新版本，提供 Apple Silicon 和 Intel 安装包。

## 本次更新

- 采用新版原生扁平化界面，统一侧栏、控件与页面布局。
- 调整组合配置分流规则行，使匹配内容与出口左右对齐。
- 支持多订阅组合、节点与策略组管理、自定义规则和应用分流。
- 提供系统代理、TUN、连接查看、日志和网络诊断。

## 安装与更新

- M 系列 Mac 选择 `arm64`，Intel Mac 选择 `x86_64`；均提供 DMG 和 ZIP。
- 更新前关闭系统代理和 TUN，退出应用，在原安装位置替换后重新打开。
- 若出现“完成更新”，点击并在 macOS 管理员授权窗口确认即可。
- 应用分流需要已授权的管理员后台服务；应用使用辅助进程联网时，以实际联网进程为准。
- 从 Build 21 及以后版本更新会保留现有配置；更早版本需重新添加订阅。

安装包使用本地 ad-hoc 签名，未经过 Apple 公证。下载后如被系统阻止，请在“系统设置 → 隐私与安全性”按提示允许打开。

Intel 包在 Apple Silicon 上通过 Rosetta 验证，尚未完成 Intel 真机验收。
