# LumaRoute 0.1.6 · Build 36

统一使用 macOS 27.0 SDK 编译与链接，最低支持版本仍为 macOS 14，所有 target 继续使用 Swift 6 语言模式，沿用现有界面。

## 本次更新

- 构建入口统一设置 `SDKROOT` 和 SwiftPM `--sdk`，固定为 macOS 27.0，避免实际编译使用 26.5、最终二进制却记录为 27.0 的不一致。
- 构建和回归脚本共用 SDK 选择逻辑，要求完整 Xcode，拒绝其他 SDK 版本或缺少 SwiftUI 宏插件的环境，不再自动退回旧 SDK。
- 增加 SDK 选择与编译产物回归测试，在构建和打包时验证应用、后台服务的 SDK 版本与 macOS 14 最低部署版本；构建阶段同时检查 CLI。
- CI 同步使用 Xcode 27 和 macOS 27.0 SDK，覆盖 Apple Silicon 与 Intel 构建。
- 更新构建说明及两种架构的 DMG、ZIP 安装包。

发布验证覆盖 Swift 单元测试、Python 脚本测试、两种架构的 CLI 回归与隔离内核冒烟测试，以及安装包签名、版本、架构、资源和文件完整性。最低 macOS 14 由编译器可用性检查和产物部署版本确认，尚未在 macOS 14 真机运行验证。

## 安装与更新

需要 macOS 14 或更新版本。M 系列 Mac 选择 `arm64`，Intel Mac 选择 `x86_64`；均提供 DMG 和 ZIP。

更新前关闭 LumaRoute 的系统代理和 TUN，再退出应用，将新包替换到 `/Applications/LumaRoute.app`。重新打开后如出现“完成更新”，点击并在 macOS 管理员授权窗口确认。从 Build 21 及以后版本更新会保留现有 SQLite 数据。从 Build 20 或更早版本更新需重新添加订阅，旧文件保留。

安装包使用本地 ad-hoc 签名，未经过 Apple 公证。下载后如被系统阻止，请在“系统设置 → 隐私与安全性”按提示允许打开。Intel 产物通过 Apple Silicon 上的 Rosetta 验证，尚未完成 Intel 真机验收。本次发布验证不替换本机已安装应用或后台服务，也不执行真实系统代理、DNS 或 TUN 接管。
