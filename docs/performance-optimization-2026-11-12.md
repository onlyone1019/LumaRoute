# 四项界面性能优化与回归验证

基线：`71b643ad90f76bbe6dd62ae4c7a6ef4551979ae8`（0.1.18 / Build 48）。对应问题与原始测量见 [性能检查](performance-audit-2026-11-12.md)。本次修改源码，不更新安装版本或发布版本号。

## 实现

- 连接页每轮渲染只筛选、排序一次，计数、表格、详情和空状态共享结果；筛选条件、比较器和响应时机保持原样。
- 连接模型使用全字段相等比较，相同快照不重复发布；原生表格仅在行内容或顺序变化时重载。跳过重载仍更新动作回调、目标策略、忙碌状态、排序描述和选择。
- 策略组子菜单在 `menuNeedsUpdate` 中首次构建；周期刷新仅访问已展开的节点菜单，关闭后重新进入时同步最新状态。普通命令菜单继续更新快捷键状态，追踪期间保持菜单结构，最后一个菜单关闭后停止定时器。
- 日志页每轮渲染共享一次筛选结果；暂停快照、继续、选中详情和导出范围保持原样。

没有引入跨轮结果缓存，没有减少实时字段更新频率，没有改动代理转发、系统代理、TUN 或用户配置。

## 验证

环境：Apple M1 Max、macOS 27.2.1、SDK 27.2，arm64 Release 构建。GUI 宿主使用生产页面与合成状态，关闭 bootstrap，不访问真实 XPC 或用户数据库。

| 验证 | 结果 |
| --- | --- |
| Swift 测试 | 108 项通过，含新增连接快照全字段比较测试 |
| Python 脚本测试 | 47 项通过 |
| 新增页面与菜单专项回归 | 基线出现 7 项预期失败；优化后 38 项全部通过 |
| 原有连接 GUI 回归 | 550 项检查、480 次批量更新通过，无表格重入警告 |
| 原有日志 GUI 回归 | 100 项检查通过，无表格重入警告 |
| CLI 原生回归 | 218 项断言通过 |
| 测试进程清理 | 强制缩短启动等待并触发超时，确认按 PID 与完整可执行路径识别的隔离进程已退出 |
| 真实 AppKit 菜单交互 | 两个策略组首次展开、勾选显示、关闭、重新打开正常，隔离宿主已退出 |
| 页面视觉检查 | 连接与日志截图保留现有布局和原生扁平风格 |
| 复审 | Standards 与 Spec 复审均无剩余发现；主审复核差异通过 |

专项测试使用操作次数而非耗时阈值：连接页和日志页每轮筛选一次，相同连接快照不渲染或重载，选择变化不重载，根菜单不预建节点，关闭的节点子菜单不参与定时状态遍历。覆盖同 ID 内容改变、筛选排序、选择消失、暂停继续、导出、动作回调更新、菜单实时状态、快捷键、结构延后重建和定时器停止。已接入 arm64 CI。

运行方式（先完成 arm64 Release 构建）：

```sh
python3 script/check_performance_regressions.py --products .build/arm64/arm64-apple-macosx/release --output work/performance-regressions
```

可用 `--baseline REF` 检查历史实现，或 `--interactive` 打开合成数据菜单宿主做真实交互验收。测试失败或超时会核对可执行文件路径后清理测试进程，避免误关其他应用。

本次验证证明重复界面工作减少和上述行为保持；不将原型测量等同于最终整页耗时收益，也不对代理吞吐、功耗或长期真实负载作新的性能承诺。未替换正在使用的应用，未执行真实节点切换或外部测速。
