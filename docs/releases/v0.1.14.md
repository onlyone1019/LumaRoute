# LumaRoute 0.1.14 · Build 44

修复自定义规则的文本编辑体验：

- 消除选中文字前约半秒的手势等待。
- 单击匹配内容输入框的空白处即可直接输入，空文本框也可直接编辑。
- 保留双击选词、拖选、搜索、撤销和上下箭头排序，以及现有页面样式。

需要 macOS 14 或更新版本。内置 Mihomo 继续使用 v1.19.33。安装包使用本地 ad-hoc 签名，未经过 Apple 公证；Intel 包为交叉构建，未在 Intel 真机验收。Release 提供双架构 DMG / ZIP、签名更新源、源码及校验文件，第三方许可见 THIRD_PARTY_NOTICES.md。

## 验证

真实规则页的隔离前后对照确认单击空白处直接输入、空文本框输入、双击选词、拖选、上下排序、搜索与撤销正常，测试未访问已安装应用的配置或后台服务。构建与产物校验统一使用 macOS 27.2 SDK，最低运行版本保持 macOS 14.0。

双架构 Release 构建、嵌套签名、SDK / 最低系统版本、DMG / ZIP 完整性和 Sparkle 更新包签名校验通过。104 项 Swift 单元测试、42 项脚本测试、Apple Silicon 和 Intel 各 218 项原生回归检查通过；Intel 回归通过 Rosetta 运行。
