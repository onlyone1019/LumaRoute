## 包含功能

- 原生 SwiftUI 桌面界面与常驻菜单栏。
- 订阅链接、文件及拖放导入，各订阅独立 User-Agent，更新失败保留可用配置。
- 节点与分组测速、最低延迟选择、故障转移和手动切换。
- 系统代理、TUN、DNS、路由、IPv6 与本机管理员后台服务。
- 自定义规则，以及 Loyalsoldier 规则订阅：选择目标策略组、自动更新、默认保留机场原分流。
- 连接查看、日志与诊断导出，内核/GEO 更新回退及本地备份恢复。

安装包包含 Mihomo 内核、GEO 数据、图标和后台服务安装资源，不包含用户订阅、节点认证信息或本机配置。

## 安装与更新

1. 更新旧版前，先关闭 LumaRoute 的系统代理和 TUN，再退出应用。
2. 打开 DMG，把 `LumaRoute.app` 拖入 `Applications`；也可以解压 ZIP 后手动放入“应用程序”。
3. 从“应用程序”打开 LumaRoute。
4. 打开“设置 → 网络 → 管理服务 → 安装并授权网络服务”，在 Terminal 手动完成管理员密码输入。
5. 等待应用自动刷新，再导入订阅、选择节点并启用所需网络接管方式。

后台服务绑定具体构建，替换到不同构建后需重新安装同步。安装服务本身不会开启系统代理或 TUN。默认混合端口 `19790`、控制端口 `19791`，与其他代理软件共存时请避免端口冲突。
