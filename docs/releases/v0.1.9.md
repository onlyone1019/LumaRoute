# LumaRoute 0.1.9 · Build 39

修复生效规则滚动后内存大涨、切换其他页面卡顿，以及连接页重复滚动时内存逐轮累积的问题。保留现有原生扁平 UI、表格布局、搜索、排序和分流入口。

## 本次更新

- 生效规则表格改用固定行高并复用行和单元格，避开自动行高计算中不断创建行内容的路径。保留原三列、列宽、背景、圆角和搜索条件。
- 连接页补齐原生行视图复用，保留既有 24 点行高、五列布局、分隔线、选择、排序、筛选和右键分流操作。
- 增加完整滚动后切页的内存回归，将生效规则压力测试纳入 CI。连接页现有回归新增三轮完整遍历与内存增长检查。

## 验证

在当前 Apple Silicon/macOS 环境下，相同 2,000 条规则隔离负载中，生效规则滚动并切页的物理内存峰值从约 902 MiB 降至约 61 MiB，概览切页从约 21.8 秒降至约 0.13 秒。两边均包含固定 120 ms 等待，该数据为单机固定负载对照，不代表所有设备的端到端延迟。

连接页 2,000 条连接三轮滚动，物理内存从修复前约 153、213、263 MiB，改善为约 91、101、100 MiB。独立页面与完整页面宿主共通过 480 次刷新回归；初始、选中、空列表三张页面 PNG 与修复前完全一致。生效规则通过 6,000 条规则三轮滚动、切页、数据替换和主题/窗口尺寸变化检查。详细记录见 [性能验证](https://github.com/onlyone1019/LumaRoute/blob/v0.1.9/docs/live-rules-performance-2026-10-18.md)。

发布提供 Apple Silicon 和 Intel 的 DMG、ZIP 及已签名 Sparkle 更新源。Intel 在 Apple Silicon 上使用 Rosetta 验证，尚未完成 Intel 真机的系统代理、TUN 或后台服务验收；也未覆盖所有 macOS 版本。

## 安装与更新

需要 macOS 14 或更新版本。M 系列 Mac 选择 `arm64`，Intel Mac 选择 `x86_64`。

0.1.8 用户可在应用内点击“检查更新”，下载完成后选择“安装并重新启动”。更新保留订阅、规则、节点选择和外观设置；需要同步后台服务时，请在本机 macOS 管理员授权窗口确认。0.1.7 及更早版本首次迁移需手动安装：先关闭系统代理和 TUN，退出应用，再替换 `/Applications/LumaRoute.app`。

安装包仍使用本地 ad-hoc 签名，未经过 Apple 公证。浏览器下载后如被系统阻止，请按“系统设置 → 隐私与安全性”的提示允许打开，或按 README 从源码构建。
