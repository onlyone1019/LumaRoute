## 本次改动

- 系统代理开关独立处理，避免重复生成、校验和重载内核配置，保留原网络恢复与冲突检查。
- 相同配置下开启、关闭各测三次：平均从 5.33 / 4.91 秒降到 0.82 / 0.87 秒，耗时减少约 83%。计时包含自动化点击及界面观察开销；新版应用内处理为 8–10 毫秒。
- 应用启动后自动检测网络服务是否需要同步，提供“完成更新”及“启用网络功能”入口。
- 在 macOS 管理员授权窗口完成同步，随后自动连接服务，无需打开 Terminal、重启或手动重新检查；同一已授权版本正常重开不重复安装。
- 保留 LumaRoute 名称，并补充 Dock 图标缺失时的本机已验证安装路径说明。

包含 Mihomo 内核、GEO 数据、图标、许可及后台服务资源。保留订阅管理、策略组、测速、规则订阅、自定义规则、连接、日志和维护恢复功能。安装包不包含用户订阅、节点凭据或本机配置。

## 安装与更新

1. 更新旧版前，关闭 LumaRoute 的系统代理和 TUN，再退出应用。
2. 从 DMG 或 ZIP 取出 `LumaRoute.app`，安装到“应用程序”；更新时替换原安装位置中的应用。
3. 打开应用。如显示“完成更新”，点击并在 macOS 管理员授权窗口中确认。
4. 首次使用可点击“启用网络功能”，或直接开启系统代理 / TUN 进入授权。授权完成后自动连接后台服务。
5. 导入订阅、选择节点并启用所需网络接管方式。安装器本身不会自动接管网络；从开关进入授权时，会继续应用该次明确选择。

若主窗口已打开但 Dock 图标仍缺失，可把原样应用包放到 `/Applications/LumaRoute/LumaRoute.app`，名称仍为 **LumaRoute**。这是本机已通过用户验收的路径规避方式，底层系统原因尚未确定。后续更新沿用该位置，不另装回原来有问题的路径。移动未修改的应用包不需要重新授权。

后台服务继续严格绑定具体构建，新版本需要同步时仍可能要求管理员授权一次。默认混合端口 `19790`、控制端口 `19791`；与其他代理软件共存时避免端口冲突。

## 签名与 macOS 提示

此包使用 **ad-hoc 本地签名**，未经过 Developer ID 签名与 Apple 公证。包内代码签名完整性验证通过，不代表通过 Gatekeeper 分发信任评估。

浏览器下载后，macOS 可能阻止启动。确认来自本仓库后，可在“系统设置 → 隐私与安全性”按系统提示手动允许打开；仍不允许时，参考 README 在本机自行构建。无需关闭 Gatekeeper 或系统完整性保护。

管理员密码只在本机系统授权窗口输入，不要发送到聊天或仓库；应用不接收、保存或传递密码。
