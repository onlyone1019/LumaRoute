# 快捷分流、应用分流、诊断与更新变化（Build 24）

2026-10-15，在多订阅组合 Build 23 的基础上实现。Apple Silicon macOS，Mihomo v1.19.32，本机构建安装，未发布 Release。

## 使用入口

- **连接**：右键某条连接，选择“此域名以后走”或“此应用以后走”，再选择订阅、策略组、直连或拒绝。在编辑器核对匹配内容后保存；详情区也有同样入口。
- **规则 → 应用分流**：添加应用，可用原生选择器选择 `.app`，自动填入其主可执行文件路径；也支持手填进程名称或完整路径、编辑、启停和删除。
- **概览 → 网络诊断**：确认测试地址后开始，分别显示控制接口、代理监听配置、系统代理、TUN、DNS 和实际访问的结果；随时取消，不修改配置或启停网络开关。
- **订阅**：内容更新成功后显示增删及修改数量，点击“查看变化”查看节点、策略组与代理提供者定义的变化；选中节点被删除时显示提示。
- **连接详情**：显示“目标 → 命中规则类型 → 来源订阅 → 实际节点”，并保留完整命中内容和代理链。进入连接页主动加载一次快照，另有“刷新”按钮；周期刷新仍受窗口可见性约束。

## 分流与保存行为

快捷规则保存到当前自定义规则集合的首位，优先于其他自定义规则、域名绑定及订阅规则。相同类型和匹配内容已存在时，编辑器明确提示替换；保存过程保留其余规则。应用分流与普通规则使用同一套匹配顺序，可在“自定义规则”中调整顺序。

组合配置有独立的自定义规则；普通单订阅沿用原有自定义规则集合。切回普通订阅不会带入组合规则。规则仅在规则模式下生效，已经建立的连接保持原出口，新连接使用新规则。

从连接创建域名规则默认精确匹配；用户可改为域名及子域名。没有域名而只有 IP 时，生成 `/32` 或 `/128` 精确地址规则。应用匹配优先使用完整进程路径，没有路径时才使用已有进程名称；未知进程不允许自动生成应用规则。

本机实测，普通用户态内核无法可靠识别进程；管理员后台服务运行的内核能够按名称、路径正确分流。未使用后台服务时应用分流页会提示前往网络设置。应用流量必须进入 LumaRoute，系统代理不会覆盖所有应用；需要覆盖不遵循系统代理的应用时使用 TUN。浏览器等应用可能由辅助进程联网，选择 `.app` 只会填入主进程路径，不能自动代表所有辅助进程。

规则编辑器会拒绝已经切换配置的旧编辑请求和不存在的目标策略。规则类型白名单扩展为 `PROCESS-NAME`、`PROCESS-PATH`，继续拒绝逗号和控制字符注入，并校验绝对路径格式。

## 诊断范围

诊断使用内核 `/version`、`/configs`、`/dns/query`、macOS 当前代理快照和一次显式 HTTP 代理请求。实际请求遵循当前路由规则，不能据此推断某个固定节点、所有网站或所有应用均正常。

DNS 必须返回有效地址记录才算成功。IP 测试地址显示“无需 DNS 解析，域名解析尚未验证”。实际请求保留 TLS 证书校验，传输失败、HTTP 5xx 为失败，HTTP 4xx 为需要检查的提示；控制接口正常不会掩盖出口失败。TUN 结果为内核报告的启用状态，不能单独证明所有系统流量已接管。

只在点击开始后访问所填测试地址，拒绝带账号密码的 URL。请求地址通过 stdin 传给传输进程，不出现在其启动参数中；取消检查或关闭弹窗会取消请求，配置改变后旧结果不再回填。

## 更新变化范围

差异在成功应用和 SQLite 提交后随订阅元数据一起保存，失败不会替换上次成功变化记录。内容没有变化时只更新元数据并保留上次实际变化详情。差异计算在主线程之外进行。

直接声明的 YAML 节点按名称比较参数，URI 来源按节点名称比较（未命名节点使用行序号，重复名称可能合并显示）。远程 provider 仅比较其定义，不能声称已比较 provider 服务器内部所有节点；界面明确显示此范围。只持久化名称和变化类别，不保存原始节点参数或密码。

现有 SQLite 表结构不变，`Profile` 可选字段保存上次变化摘要，兼容旧记录和备份。

1. 创建临时 A/B 订阅及组合，在“应用分流”保存 `/usr/bin/curl → B`：新请求返回 B 的 `osaka` 标记。
2. 重启应用后规则保留。修改 B 的节点参数、在应用中更新，展示“修改 1”及实际节点名称；恢复 B 后请求重新返回 `osaka`。

4. 右键“此应用以后走 → B”打开正确进程和目标的编辑器，相同匹配显示“保存并替换”。
5. 原生应用选择器选择 TextEdit，自动填写 `/System/Applications/TextEdit.app/Contents/MacOS/TextEdit`；取消编辑不保存新规则。
