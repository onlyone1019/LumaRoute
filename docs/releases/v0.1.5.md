# LumaRoute 0.1.5 · Build 35

收紧订阅配置权限，修复配置应用与日志处理问题，降低配置准备和日志脱敏开销，并完成 Swift 6 语言模式迁移。沿用现有界面。

## 本次更新

- 订阅顶层配置改用白名单，阻止订阅通过额外监听、隧道、服务端配置或 NTP 等字段扩大内核权限；保留正常节点、策略组、规则与受约束的 provider 配置。
- 配置应用失败时区分已经验证的成功回滚与内核状态未知。成功回滚保留原有网络接管，并恢复流量和日志状态流；状态未知时仍执行清理。
- 内核输出遇到 EOF 后移除读取回调，避免退出后空转；按完整日志行解码，保留跨数据块的中文和尾行。
- 缓存日志脱敏正则，以类型约束传递已脱敏日志，避免内核日志重复处理。
- 版本信息统一读取 Bundle 和内核元数据，诊断导出与订阅请求 UA 跟随实际版本。
- YAML 解析、SQLite 配置读取和组合订阅准备移到后台，复用配置准备阶段的策略组、节点数和选择信息，减少主线程重复解析。
- 持久化模型为缺失字段提供兼容默认值，同时保留必要标识和字段类型校验；增加冻结的 v1 JSON 契约样本、SQLite 与备份回归检查。
- Core、Helper、应用、CLI 和测试全部切换到 Swift 6 语言模式，补齐 Sendable 与并发隔离，替换弃用的 C 字符串数组解码 API。

回归覆盖恶意与正常订阅、回滚和状态流恢复、日志 EOF 与 UTF-8 分块、版本元数据、并发访问、后台配置准备以及旧持久化数据兼容。发布前运行单元测试、脚本检查和 CLI 回归，并验证两种架构的签名与安装包完整性。

## 安装与更新

需要 macOS 14 或更新版本。M 系列 Mac 选择 `arm64`，Intel Mac 选择 `x86_64`；均提供 DMG 和 ZIP。

更新前关闭 LumaRoute 的系统代理和 TUN，再退出应用，将新包替换到 `/Applications/LumaRoute.app`。重新打开后如出现“完成更新”，点击并在 macOS 管理员授权窗口确认。从 Build 21 及以后版本更新会保留现有 SQLite 数据。从 Build 20 或更早版本更新需重新添加订阅，旧文件保留。

安装包使用本地 ad-hoc 签名，未经过 Apple 公证。下载后如被系统阻止，请在“系统设置 → 隐私与安全性”按提示允许打开。Intel 产物通过 Apple Silicon 上的 Rosetta 验证，尚未完成 Intel 真机验收。本次发布验证不替换本机已安装应用或后台服务，也不执行真实系统代理、DNS 或 TUN 接管。
