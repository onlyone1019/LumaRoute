# LumaRoute 0.1.3 · Build 33

修复应用启动时 Dock 图标可能缺失的问题，统一使用 `/Applications/LumaRoute.app` 安装路径。

## 本次更新

- 以普通应用身份启动，在首个 SwiftUI 主窗口异步创建期间保持 Dock 显示资格，避免窗口尚未注册时被误判为“全部关闭”。
- 主窗口出现后再执行首次激活；主窗口打开或最小化时保留 Dock 图标，关闭全部主窗口后隐藏，菜单栏继续运行并可重新打开控制台。
- 修正 README 和安装包说明，安装到 `/Applications/LumaRoute.app`，不再使用额外的嵌套目录。
- 保留 0.1.2 的日志导出和页面缓存内存优化，以及现有原生界面和切页方式。

新增直接使用生产 AppDelegate 的窗口回归检查，覆盖启动、延迟创建窗口、最小化、关闭、重开及多窗口行为。修改前 4 项启动检查失败，修复后 13 项全部通过。本机在标准安装路径验证时，用户确认 Dock 图标正常显示。详见 [Dock 启动修复与验证](../dock-launch-2026-10-16.md)。

## 安装与更新

需要 macOS 14 或更新版本。M 系列 Mac 选择 `arm64`，Intel Mac 选择 `x86_64`；均提供 DMG 和 ZIP。

更新前关闭 LumaRoute 的系统代理和 TUN，再退出应用。将新包安装或替换到 `/Applications/LumaRoute.app`，重新打开后如出现“完成更新”，点击并在 macOS 管理员授权窗口确认。从 Build 21 及以后版本更新会保留现有配置。

安装包使用本地 ad-hoc 签名，未经过 Apple 公证。下载后如被系统阻止，请在“系统设置 → 隐私与安全性”按提示允许打开。

Intel 产物在 Apple Silicon 上通过 Rosetta 验证，尚未完成 Intel 真机验收。
