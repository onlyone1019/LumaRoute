# 真实订阅导入验证

2026-10-13，在本机使用用户提供的订阅进行验证。本文不保存订阅地址、Token 或节点认证信息。

已定位并修复三个实现问题：

- 下载默认使用系统代理，可能导致订阅 HTTPS 连接失败。改为直接下载，保持证书校验；地址只通过进程标准输入传递，不写入参数或临时配置文件。
- 未打包 GEOIP 数据库，含 GEOIP 规则的配置首次校验卡在数据库下载。打包官方 GeoIP/GeoSite 数据库，下载时核对 GitHub 发布资产 SHA256；启动前补齐运行目录缺失资源。
- 普通节点 `provider-name` 返回空字符串，被误当成有效 provider 名称，测速请求返回 404。空名称规范为无 provider；虚拟 Compatible provider 不再覆盖节点来源。
