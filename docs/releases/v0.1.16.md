# LumaRoute 0.1.16 · Build 46

- 链式代理使用“前置代理”和“落地节点”描述流量路径。移除链路列表上方的长说明，内核未就绪时显示一行提示。
- 内置 Mihomo 更新至 [v1.19.34](https://github.com/MetaCubeX/mihomo/releases/tag/v1.19.34)，包含 TUN 自动路由和 HTTP CONNECT 等修复。构建时核对本地内核文件的 SHA-256，确保打包版本与锁定清单一致。

需要 macOS 14 或更新版本。已安装带 Sparkle 版本的用户可在应用中检查更新。如出现“完成更新”，按 macOS 提示授权同步后台服务。

提供 Apple Silicon 和 Intel 的 DMG、ZIP、签名更新源、源码及 SHA-256 校验文件。安装包使用 ad-hoc 签名，未经过 Apple 公证。Intel 包为交叉构建。
