# LumaRoute 0.1.11 · Build 41

修复切换订阅时重复下载远程规则导致的等待，保留现有原生扁平 UI，以及此前的日志页、规则页和连接页性能修复。

## 本次更新

- 相同远程规则提供器可复用本机缓存，避免每次切换配置都重新下载。
- 支持从近期配置中寻找缓存，覆盖切走再切回，以及后台服务重新启动后的切换。
- 规则地址、行为、格式、请求头或更新间隔改变时，不复用不匹配的缓存；保留每个配置的独立文件供失败回退使用。首次加载、缓存过期或近期配置中没有可复用文件时，仍需正常下载规则。

## 验证范围

在隔离 Mihomo 实例中，为本机规则服务注入 1.5 秒响应延迟，修复前重复重载仍耗时约 1.5 秒；缓存就绪后，修复后的两次重载约为 8 ms、7 ms，下载次数由含首次加载的 3 次降至 1 次。这是规则重载阶段的测量，不代表界面整次切换或首次下载耗时。详细结果见 [订阅切换诊断记录](../subscription-switch-performance-2026-10-19.md)。

新增回归覆盖缓存复用、切走再切回、runner 重建、规则定义变化、外部路径拒绝、文件权限与旧配置缓存保留。

## 安装与更新

需要 macOS 14 或更新版本。M 系列 Mac 选择 `arm64`，Intel Mac 选择 `x86_64`。交叉构建及 Rosetta 检查不代替 Intel 真机系统代理、TUN 或后台服务验收。

0.1.8 及以后版本可在应用内点击“检查更新”，下载完成后选择“安装并重新启动”。更新保留配置；需要同步后台服务时，请在本机 macOS 管理员授权窗口确认。手动替换时，先关闭系统代理和 TUN、退出应用，再替换原安装位置的应用。

安装包使用本地 ad-hoc 签名，未经过 Apple 公证。浏览器下载后如被系统阻止，请按“系统设置 → 隐私与安全性”的提示允许打开，或按 README 从源码构建。
