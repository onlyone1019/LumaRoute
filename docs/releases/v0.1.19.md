# LumaRoute 0.1.19 · Build 49

本版本减少连接页、日志页和菜单栏的重复界面工作：

- 连接页每轮只筛选、排序一次，计数、列表、详情和空状态共享结果。
- 相同连接快照不重复触发刷新，仅改变选中连接时不再整表重载；流量、进程、策略链等字段变化仍会正常更新，右键操作保持有效。
- 策略组菜单在首次展开时构建节点，定时刷新只处理已展开节点；保留勾选、测速进度、快捷键和菜单关闭后的定时器停止行为。
- 日志页每轮复用筛选结果，保留暂停、继续、详情、自动滚动和导出行为。

新增 38 项页面与菜单专项回归及连接模型全字段比较测试。性能改动已通过 108 项 Swift 测试、47 项脚本测试、650 项现有 GUI 检查和 218 项 CLI 断言，并完成原生菜单交互与页面样式核对。详细结果见 [性能优化与回归验证](https://github.com/onlyone1019/LumaRoute/blob/v0.1.19/docs/performance-optimization-2026-11-12.md)。这些优化减少界面计算，不代表代理网速或整体 CPU 按相同比例提升。

需要 macOS 14 或更新版本，内置 Mihomo v1.19.34。已安装带 Sparkle 版本的用户可在应用中检查更新。如出现“完成更新”，按 macOS 提示授权同步后台服务。

提供 Apple Silicon 和 Intel 的 DMG、ZIP、签名更新源、应用与第三方源码及 SHA-256 校验文件。安装包使用 ad-hoc 签名，未经过 Apple 公证。Intel 包为交叉构建，未做 Intel 真机安装验收。
