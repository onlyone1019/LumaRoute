# LumaRoute 0.1.4 · Build 34

修复隐藏应用、恢复窗口及快速关闭重开时 Dock 图标可能缺失的问题，保留现有界面、页面缓存和切页方式。

## 本次更新

- 按主窗口实际打开、关闭管理 Dock 状态，避免隐藏或暂时不可见的窗口被误判为已经关闭。
- 关闭最后一个主窗口后合并短时间内的状态更新；快速重开会立即取消待执行的 Dock 隐藏，复用已有的隐藏或最小化窗口。
- 统一去重激活策略写入，退出时取消待执行的隐藏任务，减少相反模式切换的交错。
- 重复构建时更新应用包的目录修改时间，避免 Launch Services 沿用旧的包元数据。
- 扩充窗口回归检查，可在已有辅助功能权限下只读检查真实 Dock 项数量，无需重启 Dock 或改变安装路径。

已通过 29 项窗口与 Dock 检查，其中 9 项直接验证 Dock 项数量；页面缓存、菜单和交互回归 41 项通过。同一窗口管理实现已在 `/Applications/LumaRoute.app` 验证启动、隐藏、恢复、关闭重开和最小化，当前代理未改变。

本次修复针对已复现的窗口生命周期缺陷。此前还观察过应用策略为普通应用但 Dock 未显示的安装状态，尚未证明所有历史安装故障都由同一根因造成；详细证据与验证范围见 [Dock 生命周期复查](https://github.com/onlyone1019/LumaRoute/blob/v0.1.4/docs/dock-lifecycle-2026-10-17.md)。

## 安装与更新

需要 macOS 14 或更新版本。M 系列 Mac 选择 `arm64`，Intel Mac 选择 `x86_64`；均提供 DMG 和 ZIP。

更新前关闭 LumaRoute 的系统代理和 TUN，再退出应用，将新包替换到 `/Applications/LumaRoute.app`。重新打开后如出现“完成更新”，点击并在 macOS 管理员授权窗口确认。从 Build 21 及以后版本更新会保留现有配置。与其他代理工具共存时，请避免端口冲突。

安装包使用本地 ad-hoc 签名，未经过 Apple 公证。下载后如被系统阻止，请在“系统设置 → 隐私与安全性”按提示允许打开。Intel 产物在 Apple Silicon 上通过 Rosetta 验证，尚未完成 Intel 真机验收。
