# LumaRoute 0.1.18 · Build 48

本版本修复日常使用中的状态恢复问题：

- GEO 数据更新、回退和失败恢复保留当前实际代理模式，避免界面与内核模式不一致。
- 首次启动遇到临时故障后自动重试，并保留原有“启动时连接”、系统代理和 TUN 设置。
- 检测到网络被其他程序接管时明确提示并停止自动接管，避免后台服务重连覆盖其他程序的网络设置。
- 补充启动恢复、服务重连、网络接管冲突、GEO 模式保持和协议兼容的回归测试。

需要 macOS 14 或更新版本，内置 Mihomo v1.19.34。已安装带 Sparkle 版本的用户可在应用中检查更新。如出现“完成更新”，按 macOS 提示授权同步后台服务。

提供 Apple Silicon 和 Intel 的 DMG、ZIP、签名更新源、源码及 SHA-256 校验文件。安装包使用 ad-hoc 签名，未经过 Apple 公证。Intel 包为交叉构建，未做 Intel 真机安装验收。
