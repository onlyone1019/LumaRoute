# LumaRoute 0.1.10 · Build 40

改善日志页打开与持续刷新速度，修复日志表格重入警告和缩放窗口后的自动滚动问题。保留现有原生扁平 UI、日志行内容、筛选、选择详情、暂停、复制与导出操作。

## 本次更新

- 日志表格改由原生表格协调数据更新、尺寸变化和自动滚动，继续复用原有 SwiftUI 行内容。将尺寸失效与跟随末行操作放到表格委托回调之外，避免重入。
- 筛选条件在每次计算时读取一次；无筛选时直接使用日志快照，未选择日志时跳过详情查找，减少无效遍历和观察依赖。
- 增加真实日志页的隔离 GUI 回归并纳入 CI，覆盖 2,000 条日志、页面重建、持续追加、筛选、选择、暂停、自动滚动、清空、主题和窗口缩放。

## 性能验证

在同一 Apple Silicon/macOS、SDK、Release 构建参数与 2,000 条合成日志负载下，与 0.1.9 对照：

| 指标 | 修复前 | 修复后 |
| --- | --- | --- |
| 首次打开 p50（3 个独立进程） | 331.7 ms | 255.9 ms |
| 页面回收后重建 p50（6 次） | 287.8 ms | 220.4 ms |
| 40 次更新累计耗时 p50（3 轮） | 3,746.0 ms | 2,448.9 ms |
| 三轮回归的表格重入警告 | 18 | 0 |
| Time Profiler 采样 CPU 时间 | 8,699 ms | 6,091 ms |

更新耗时包含主线程更新与布局，不包含脚本刻意等待，不代表输入到屏幕显示的端到端延迟。Time Profiler 数据为固定脚本下的采样对照，包含截图等测试操作，不代表日常 CPU 占用率。修复后三轮共 300 项日志页检查通过；另有 23 项完整页面生命周期检查，覆盖真实 61 秒空闲回收及状态恢复。

本次存在内存取舍：Allocations 测试终点的持久堆分配由 36.7 MiB 增至 55.1 MiB，累计堆分配由约 1,582.6 MiB 降至 1,383.7 MiB。持久堆分配不同于进程物理内存，也不能据此断定泄漏。独立完整页面测试中，日志持续更新后物理占用约 130.8 MiB，空闲回收后约 90.5 MiB；这些结果不代替长时间运行或其他设备验收。

浅色日志列表像素一致率约 99.976%，差异集中在状态圆点边缘；所测选中、空列表与 Unicode 场景完全一致。深色主题经过视觉对比，未宣称所有主题逐像素一致。

## 安装与更新

需要 macOS 14 或更新版本。M 系列 Mac 选择 `arm64`，Intel Mac 选择 `x86_64`。Intel 包通过交叉构建及 Rosetta 检查，尚未完成 Intel 真机系统代理、TUN 或后台服务验收。

0.1.8 及以后版本可在应用内点击“检查更新”，下载完成后选择“安装并重新启动”。更新保留配置；需要同步后台服务时，请在本机 macOS 管理员授权窗口确认。手动替换时，先关闭系统代理和 TUN、退出应用，再替换原安装位置的应用。

安装包继续使用本地 ad-hoc 签名，未经过 Apple 公证。浏览器下载后如被系统阻止，请按“系统设置 → 隐私与安全性”的提示允许打开，或按 README 从源码构建。
