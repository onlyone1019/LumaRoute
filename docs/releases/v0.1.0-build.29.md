# 0.1.0 · Build 29

macOS 14+ 开发预览版，提供 Apple Silicon（arm64）与 Intel（x86_64）安装包。仓库继续保持私有。

- LumaRoute 自有代码采用 MIT，署名 onlyone1019；第三方组件保留原许可和来源说明。
- 用 imagegen 生成的新猫形菜单图标替换当前源码中的 ClashX.Meta PNG，提供真实透明通道和 18 / 36 像素资源。
- 安装包带有 MIT、第三方声明和相关许可；清除复用构建目录可能残留的旧 PNG。旧素材的 AGPL 来源记录继续保留；Build 17、19、21、28 的 Release 和附件已在外部备份后删除，Git 标签保留。
- 补充贡献指南、安全报告说明、Issue / PR 模板和双架构构建 / 秘密扫描 CI 定义。
- 补齐 GEO 可编辑输入、固定工具与完整依赖源码，支持无网络重建，三份产物 SHA-256 与现有数据一致；不再依赖会滚动变化的 `latest` 数据下载。
- 已执行历史、截图及现有 Release 的敏感信息检查，范围、结果和未完成项见 [开源准备报告](../open-source-preparation-2026-10-15.md)。

提供 macOS 14+ 的 `arm64` 和 `x86_64` DMG、ZIP。两种架构各 218 项核心回归、隔离内核冒烟和菜单资源检查通过；Intel 产物通过 Rosetta 验证，尚未完成 Intel 真机、完整 TUN 或管理员服务验收。包继续采用 ad-hoc 签名，未公证。

已在仓库外备份后清理旧作者邮箱和个人路径，并补齐 GEO 规范化生成输入及离线重建证据。仓库继续保持私有；历史清理不意味着第三方副本或 GitHub 服务端缓存已经消失。

四个安装包的逐文件一致性、签名、架构及校验值见 [Build 29 发布验证记录](../build29-release-verification-2026-10-15.md)。Release 同时提供 SHA256SUMS、Mihomo v1.19.32 与 Yams 6.1.0 官方源码归档，以及 GEO 规范化输入、固定工具和完整依赖源码归档；具体来源及摘要见附件 `source-manifest.json`。

2026-10-15 补充 GEO 二级来源署名与许可正文，并更新本 Release 的双架构 DMG / ZIP、GEO 源码附件、源码清单和校验文件。应用代码、后台服务、内核和 GEO 数据未改变，所有 Git 标签保持原对象及目标。当前安装包校验值见发布验证记录的“当前发布：在线 GEO 更新与回退的许可保护”部分。

许可补充涉及 MaxMind GeoLite / CC BY-SA、V2Ray 及其他规则来源；详见 [GEO 专项声明](../../Resources/Licenses/GeoData-NOTICE.md)。后续已将 xishang0128/rules 的两类输入替换为 V2Ray MIT 与 ACL4SSR CC BY-SA 4.0 的固定来源；GeoLite 数据更新与旧版本处置条款仍需持续遵守，仓库继续保持私有。

当前双架构安装包已包含替换后的 GEO：`biliintl` 7 条、`sharepoint` 3 条，其他 1,553 个分类和全部 IP 数据不变。原始来源及许可证已随 `LumaRoute-GEO-inputs-2026-10-15-licensed-rules.tar.gz` 提供，全部新摘要见 `SHA256SUMS.txt`。每种架构的 20 个真实内核分类匹配用例、218 项回归和隔离冒烟通过。Git 标签不移动，资源对应源码由 `source-manifest.json` 的 `geo_data_source_commit` 标识。

后续已将同一许可策略接入应用内手动在线更新与旧快照回退：验证上游文件后替换 biliintl / sharepoint，再校验内核与事务写入。策略缺失 / 摘要错误拒绝维护操作，备份原件保留；不后台强制覆盖已有用户运行目录。
