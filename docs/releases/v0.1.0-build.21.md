## 本次改动

- 设置、订阅元数据及内容、规则、策略、节点选择、完整订阅链接和控制接口密钥统一存入 `~/Library/Application Support/LumaRoute/lumaroute.sqlite`，应用不再访问钥匙串。
- 订阅导入与删除、规则内容及元数据通过 SQLite 事务保存；失败回滚。保留订阅当前/上一版本，损坏或不支持版本的数据库会报错，不静默清空。
- 普通备份采用 SQLite 格式，排除完整订阅链接和控制密钥；恢复时保留本机凭据。目录权限为 `0700`，数据库为 `0600`。这是普通 SQLite 文件，未加密。
- 外观、登录启动、启动后连接、测试并发数、默认订阅更新间隔独立保存，不重新生成、校验或重载内核配置，不取消测速或重启状态流。影响内核的设置继续走配置应用流程。
- 按窗口和页面刷新：后台节点每 10 秒，provider 每 30 秒；连接列表与进程补全仅在连接页可见时执行，规则页按需读取；进入页面或恢复窗口会即时刷新。控制接口与服务健康检查保留约 2 秒心跳。
- 保留系统代理独立开关、应用内服务授权、网络恢复及既有 Dock 行为。内核、GeoData、运行 YAML 和系统恢复记录继续使用必要的文件。

普通设置四次界面保存平均从约 **4.40 秒降到 0.94 秒**，减少约 79%，包含自动化操作开销。实际 AppStore 对回环服务模拟 60 秒调度时，隐藏窗口/设置页 HTTP 请求由 **150 次降至 38 次**，减少约 75%；不代表整机 CPU 或耗电同比下降。SQLite 版独立保存回归约 9 ms，界面单次测试约 506 ms，不能与四次均值直接作同口径比较。

## 安装与更新

1. 关闭 LumaRoute 的系统代理与 TUN，再退出应用。
2. 从 DMG 或 ZIP 取出 `LumaRoute.app`，替换原安装位置中的应用并打开。
3. 如显示“完成更新”，点击并在 macOS 管理员授权窗口确认；授权完成后自动连接服务。
4. 重新添加订阅、选择节点，再启用所需网络接管方式。首次安装也可从“启用网络功能”或系统代理/TUN 开关进入授权。

本包包含 Mihomo、GEO 数据、图标、许可及后台服务资源，不包含用户数据库、订阅、节点凭据或测试数据。

主窗口打开后如仍无 Dock 图标，可沿用本机已验证路径 `/Applications/LumaRoute/LumaRoute.app`，名称仍为 LumaRoute；之后在该位置更新。后台服务绑定具体构建，新版本同步仍可能需要一次管理员授权，与钥匙串访问无关。
