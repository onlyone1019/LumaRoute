# LumaRoute 0.1.20 · Build 50

本版本整理内核恢复和后台服务代码，保留现有代理、TUN 及界面操作流程。

- 集中管理内核恢复原因、重试次数与等待时间。配置切换后统一检查刷新结果是否仍适用，避免旧请求覆盖新状态。
- 将后台服务控制逻辑移到独立文件，沿用目录所有权、权限和符号链接校验。
- 服务重连回归通过实际应用状态流程验证首次失败、等待后重试及连接保持。基线对照固定使用同一提交的源码，性能检查直接编译生产文件。

需要 macOS 14 或更新版本，内置 Mihomo v1.19.34。可从应用内“检查更新”下载并安装。如出现“完成更新”，按 macOS 提示授权同步后台服务。

提供 Apple Silicon 和 Intel 的 DMG、ZIP、签名更新源、源码及 SHA-256 校验文件。安装包使用 ad-hoc 签名，未经过 Apple 公证。Intel 包为交叉构建，未做 Intel 真机安装验收。
